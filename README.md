# Meu Projeto C# + HTML/JS

Projeto de teste que simula um sensor com **C#** e exibe/controla os dados via **HTML/JS**.  
Funciona no **Acode/Termux** em Android e pode ser acessado em outros dispositivos na mesma rede.

## Estrutura do projeto

# Rodar backend
cd backend
npm install
npm start


# Rodar simulador
cd simulador
pip install requests
python simulador_sensor.py
